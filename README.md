# 픽컷 PickCut

AI 헤어 진단 & 실시간 미용 매칭 앱의 **웹 프로토타입**입니다 (대학 수업 조별 프로젝트).

**바로 열기 → https://frontback333.github.io/pickcut/**

## 쓰는 법
- **휴대폰**: 링크를 열면 앱처럼 전체 화면으로 보입니다.
  아이폰은 Safari 공유 버튼 → "홈 화면에 추가", 안드로이드는 Chrome 메뉴 → "홈 화면에 추가" 하면 앱 아이콘으로 열 수 있어요.
- **컴퓨터**: 가운데 휴대폰 화면 + 오른쪽 개발자 도구(화면 목록·상태)가 보입니다. 창이 좁으면 오른쪽 위 `DEV` 버튼으로 엽니다.
  발표할 때 개발자 도구를 숨기려면 주소 끝에 `?dev=0` 을 붙이세요 → https://frontback333.github.io/pickcut/?dev=0
- 특정 화면 바로 열기: 주소 끝에 `#/화면이름` (예: `#/Store`, `#/MatchSetup`).

## 알아 둘 점
- 프로토타입입니다. 로그인·결제·예약·주문은 실제로 이뤄지지 않고, 모든 데이터는 예시입니다.
- 카메라 사진은 브라우저 메모리에만 있고 어디에도 올리거나 저장하지 않습니다. 새로고침하면 처음 상태로 돌아갑니다.
- 지도는 네이버 지도를 쓰고, 쓸 수 없을 때는 OpenStreetMap 으로 바뀝니다.
